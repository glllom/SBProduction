- [ ] **Order** (Заказ)
  - Поля по умолчанию: `default_product_type`, `default_product_family`, `default_product_series`.
  - Отделка/Покраска: `default_front_finish`, `default_color_notes` (Text).
- [ ] **OrderCustomizer** (Глобальные кастомайзеры Заказа)
  - Ссылка на `Order`, `Customizer` и 5 полей фактических значений (`value_num_1..4`, `value_text_1`).
- [ ] **OrderGroup** (Группа дверей в заказе)
  - FK на `Order`.
  - Выбор конструктива: `product_series`, `product_model` (под капотом).
  - Переопределения: `front_finish` (с валидацией на совместимость с серией), `color_notes` (Text).
- [ ] **OrderGroupCustomizer** (Кастомайзеры группы)
  - FK на `OrderGroup`, `Customizer`, значения полей + флаг `is_inherited` (bool).
- [ ] **OrderItem** (Конкретная дверь / Данные замерщика)
  - FK на `OrderGroup`.
  - Поля: `width`, `height`, `opening_direction`, `room_number` (маркировка), `notes` (комментарии).
